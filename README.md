"Скільки записів у вашому ARP-кеші? Що вони означають?"
-

У мене є лише два записа (таблиці) arp.

В загальному таблиця потрібна для кешування результатів з протоколу arp. Коли наш айпі адресс
звернувся й получив мак, він додається в кеш для того щоб лишній раз не витрачати ресурси.

Таблиця побудована так: айпі, мак, тип

айпі — це адреса пристрою, до якого ми хочемо звернутися

мак — це фізична адреса цього пристрою в локальній мережі

Тип - це визначення чи дані були повернуті динамічно, чи статично. Динамічно задається автоматично. Статична - ні.


Завдання 2

Виконайте розрахунки для наступних IP-адрес:
-

192.168.1.100/24
10.0.5.50/16
172.16.8.200/20
Для кожної адреси визначте:

Клас мережі (A, B, C)

Мережеву адресу (Network Address)

Broadcast адресу

Діапазон доступних хостів

Кількість можливих хостів у підмережі

Маску підмережі в десятковому форматі

Відповідь:
-

1) 192.168.1.100/24

Клас мережі: C (192)

Мережева адреса: 192.168.1.0

Broadcast адреса: 192.168.1.255

Діапазон доступних хостів: 192.168.1.1 -> 192.168.1.254

Кількість можливих хостів у підмережі: 2^8 - 2 = 254

Маска підмережі в десятковому форматі: 255.255.255.0

2) 10.0.5.50/16

Клас мережі: A (10)

Мережева адреса: 10.0.0.0

Broadcast адреса: 10.0.255.255

Діапазон доступних хостів: 10.0.5.1 -> 10.0.255.254

Кількість можливих хостів у підмережі: 2^16 - 2 = 65,534

Маска підмережі в десятковому форматі: 255.255.0.0

3) 172.16.8.200/20

Клас мережі: B (172)

Мережева адреса: 172.16.0.0

Broadcast адреса: 172.16.15.255 (255 - 240 = 15)

Діапазон доступних хостів: 172.16.0.1 -> 172.16.15.254

Кількість можливих хостів у підмережі: 2^12 - 2= 4094

Маска підмережі в десятковому форматі: 255.255.240.0

Як швидко з'являється запис у ARP-кеші після ping?
-

Дуже швидко. Так як ми пінгуємо ЛОКАЛЬНУ адресу, виклик сам по собі швидкий.

Що таке ARP-запит і ARP-відповідь?
-

ARP-запит - це коли комп'ютер питає "чий це айпі?" всім мережам, а відповідь- це мак адреса, яка відгукнулась на питання


Чому MAC-адреси важливі тільки в локальній мережі?
-

Тому що мак адреси є тільки лише в межах локальної мережі. вони не маршрутизуються між мережами

Що станеться, якщо два пристрої матимуть однакову IP-адресу
-

Конфлікт IP. Мережа дуже легко плутається
