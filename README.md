-

192.168.1.100/24

Для кожної адреси визначте:

Клас мережі (A, B, C)

Мережеву адресу (Network Address)

Broadcast адресу

Діапазон доступних хостів

Кількість можливих хостів у підмережі

Маску підмережі в десятковому форматі

Відповідь:
-

1) 192.168.1.100/24

Клас мережі: C (192)

Мережева адреса: 192.168.1.0

Broadcast адреса: 192.168.1.255

Діапазон доступних хостів: 192.168.1.1 -> 192.168.1.254

Кількість можливих хостів у підмережі: 2^8 - 2 = 254

Маска підмережі в десятковому форматі: 255.255.255.0

2) 10.0.5.50/16

Клас мережі: A (10)

Мережева адреса: 10.0.0.0

Broadcast адреса: 10.0.255.255

Діапазон доступних хостів: 10.0.5.1 -> 10.0.255.254

Кількість можливих хостів у підмережі: 2^16 - 2 = 65,534

Маска підмережі в десятковому форматі: 255.255.0.0

3) 172.16.8.200/20

Клас мережі: B (172)

Мережева адреса: 172.16.0.0

Broadcast адреса: 172.16.15.255 (255 - 240 = 15)

Діапазон доступних хостів: 172.16.0.1 -> 172.16.15.254

Кількість можливих хостів у підмережі: 2^12 - 2= 4094

Маска підмережі в десятковому форматі: 255.255.240.0

Чому MAC-адреса призначення змінюється на кожному хопі, а IP-адреса залишається незмінною?
-

Мак адреса працює тільки в межах локальної мережі. Коли пакет доходить до маршрутизатора, старий фрейм видаляється і створюється новий фрейм для наступної мережі. Через це мак адреси source/destination змінюються на кожному хопі.

айпі залишається незмінною, тому що вона використовується для маршрутизації пакета від початкового пристрою до кінцевого вузла через усі мережі інтернету.

Що таке TTL і як він запобігає нескінченним циклам?
-

TTL — це поле в IP-пакеті, яке визначає максимальну кількість маршрутизаторів (hop), через які може пройти пакет.

якщо TTL > 0 -> пакет передається далі
якщо TTL = 0 -> пакет знищується

Чому 127.0.0.1 завжди вказує на ваш власний комп'ютер?
-

Адреса 127.0.0.1 є спеціально зарезервованою loopback-адресою. Операційна система автоматично направляє пакети з цією адресою назад до самого комп’ютера без виходу у фізичну мережу.

Яка MAC-адреса у loopback інтерфейсу? Чому?
-

Loopback інтерфейс зазвичай не має реальної MAC-адреси, тому що він є віртуальним і не використовує Ethernet або Wi-Fi. Пакети не передаються через фізичну мережу, тому MAC-адреса не потрібна.

Чи проходять пакети до 127.0.0.1 через мережеву карту?
-

Ні. Пакети обробляються всередині мережевого стеку операційної системи і не виходять на фізичний мережевий адаптер.

Яка різниця між 127.0.0.1 та 0.0.0.0?
-

127.0.0.1 - loopback, тобто цей комп'ютер
0.0.0.0 - невідома, або будь-яка адреса
